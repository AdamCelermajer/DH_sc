# Campaign audio integration

Audio source implementation now connects the persistent Application manager to a selected campaign provider lease and a common mixer delivery route. Work is batched for the integrated milestone; no new compiler, test, emulator, WSL, source-proof packet or freeze was run for these changes.

The reached initial-front audio preload now preserves source missing-file status. IDA Initialize36c2e4 calls LoadSound3699fc without checking its return and continues the preload loop. LoadSound allocates and stores a DataHandle receiver even when LoadDataSource86b144 returns an invalid id=-1 handle. The native asset adapter distinguishes genuine found=false from backend failure. The SAME sample bank retains a stable unavailable UID slot with its exact URI diagnostic and no sample; source_slot_ready_v94 remains false, no bytes are substituted and no voice/pin is created. Raw preload completes that original operation and the whole initializer can finish; later play requests still report the unavailable datasource. Missing transport, malformed metadata and decoder failures remain explicit failures. Preload Debug uses the actual isTracingPreload_SFX key. Source initialization completion therefore does not assert full audio availability or audible parity.

`audio_campaign_bridge_v46` retains the actual World, GS, canonical Level, settings, RNG and camera owners. `model_renderer::publish_campaign_audio_v46` verifies the produced campaign borrow and automatically binds the real current-Level borrower, actual Debug/Online byte5, exact isTracingSFX query and original Listener bytes.
