# B088 report: speech-bubble context button never switches to attack, Space does nothing at the NPC

Branch fix/b088 (from windows-foundation 19613921), build `DH_wt/build-fix088` (exit 0), ctest: only `session_skill_binding` fails (allowed).

## Root cause
Every TalkToNPC quest NPC was registered as a permanent type-3 object-of-interest candidate (main.cpp, P16 SPACEBTN loop; `eligible` defaulted to true). After the quest was accepted (or while it was locked) the NPC stayed the OOI forever: the HUD button kept the speech bubble, a held button never attacks while an OOI exists (source Cmd_UseOOI replaces Cmd_Attack), and Space only re-raised TalkToNPC, which matches no objective, so nothing happened. Original mask89 does not admit a living unregistered nonmerchant friendly NPC. This is the initial B088 registration diagnosis; the admission repair below adds current owner gates.
