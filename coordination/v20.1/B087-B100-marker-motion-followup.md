Current integration draws the shared marker mesh in `main.cpp` around 7417–7440. It uses `placed.definition.placement` unless a separate CombatSession actor exists. The immutable definition placement therefore causes the observed drift.

Keep the existing CombatSession position and dead-actor behavior when a live actor exists; otherwise place both marker variants at `PopulationActor.transform` so ordinary placed actors and campaign-moved actors share the same live state. No extra filter or marker state change is needed.
