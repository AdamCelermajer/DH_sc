## Implementation and verification

Implemented a bounded correction to the existing opaque L1 Sp pass. `main.cpp` now transports authored specular RGB alongside ambient/diffuse. `source_l1_specular_gl.inc` computes the original half-vector/attenuation/gloss equation on the GPU, keeps the inverse-transpose normal unnormalized and samples only SpecularSampler blue. Eye-space arithmetic is equivalent to the original world-space equation because the view rotation is orthonormal. The custom varying preserves values above1 until after the blue texture sample; fixed primary color would prematurely clamp them. No guessed strength/headroom multiplier is introduced. Program creation/link failure is explicit; the program restores the previous binding after each pass and releases resources only in its owning live context/thread. Existing opaque/no-alpha/sourcePass admission is unchanged.

`source_l1_specular.hpp` is a finite-domain independent CPU oracle for focused checks, not the production rendering path. An early proposed CPU color-array transport was rejected by the reviewer because primary-color clamping would fail strong attenuation; the final GPU implementation is the one tested below.

The original adds base+specular before final clamp. The two-pass backend still clamps base and specular separately before saturating addition; for the tested nonnegative authored light/texture domain this gives the same saturated RGB. Existing diffuse fixed-function headroom and normalized baked-normal limitations remain. Transparent/alpha-tested Sp, native fog enrollment, original automatic/static-light attachment and Android/lowp device equivalence are not claimed repaired. Desktop L1 Sp now requires GL2 shader support; tested native WGL supports it, Linux/SDL is not runtime-tested here.
