## B. Harness and process notes (for root)

1. `quiet_run.ps1` timeouts do not stop the game. `TerminateProcess` kills the `cmd.exe` wrapper only, so the `dh-foundation.exe` child keeps running (10 orphans from the 20:00 batch). I stopped exactly those 10 PIDs (rc4 path, `--startup-config run.args`, created by this batch). No other process was touched. The script needs a fix (kill the process tree) before the next batch; verifiers do not change code.
2. Several existing menu-mode templates (B046, B050, P14 f-select, P14 HUD) need `--skip-boot` now.
3. The first `h-hud-cur1` run used a stale save (see 4j); the corrected run is `h-ab-a`.
4. Intro movie comparison used the preview-10 copy of `intro.mp4` (1280x720, 50.29 s); the boot movie matches the converted `.mpg` within PSNR, not the original frame-for-frame.
