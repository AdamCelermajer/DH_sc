### Recovered original logic

- `port/level-world/reference/character-loot-world-v8/original-source.asm` contains the Item/physical path. `POItem::onCollisionBegins` at `0x4702a8` resolves the shared Item handle/type and Character; `ItemObject::OnCollisionBegins` at `0x3ec048` calls `GetInteractionType` via vtable `+0x90`. For the normal item result `-1`, it requires `CharStateMachine::SM_IsMoving(0)` and stores the Character in Item `+0x2e4`. `GameObject::Update` `0x38cbe8` then calls the Item vtable's `Interact` (`0x3ed144`) with that Character and clears `+0x2e4`.
- Contact/target caller gates are separate from transfer gates. `ItemObject::IsInteractive` `0x3ec014` requires Item bytes `+0x81 == 0` and `+0x80 != 0`, then `!HasBeenLooted`; `HasBeenLooted` is `0x3ebffc` and reads the embedded inventory. `OnCollisionBegins`'s non-`-1` branch requires Character `OOI +0x14a4` to equal the Item and then `PlayerManager::IsLocalPlayer` `0x36effc` before installing the tooltip path. The normal `-1` walkover branch instead depends on contact plus moving state.
- Whole `ItemObject::Interact` at `0x3ed144` first rejects a looted/empty Item, a mismatched owner at `+0x3bc`, and a same-player pickup lock: Item `player_id +0x3c0` is compared with `PlayerInfo +0x678`, and positive lock `+0x3b8` refuses that owner. It then requires `IsPlayer`; equipment pickups check AutoTransmute/powers and inventory fullness, while type-14 potions check `GetNumPotions < capacity +0x3a8`. Successful transfer runs inventory/gold/quest effects, pickup audio, tooltip/glow cleanup, loot FX, despawn, and stat increment. Thus name/HP loss alone cannot establish successful or refused pickup.
- Reused exact source/portable handoffs: `port/level-world/reports/world-item-live-v5-handoff.md` describes the same Gear transfer and gates; `coordination/claude-preview15/B063-report.md` records the mobile `HUDControls::Update` `0x41a780` OOI fallback and the intentional PC rule that Space/E are not loot keys. Current desktop production is the analogous walkover adaptation, not a Space/E pickup route.
