# Reference resolution rules

- **pydata-name-blocks** (PROVEN; PROVEN) — PyData name blocks are count-prefixed lists of length-prefixed UTF-8 strings; row index is zero-based in serialized order. Evidence: `port/game-data/animation_tables.cpp Reader::strings and load_animation_tables; port/game-data/effects_tables.cpp Reader::names.`
- **audio-row-index** (PROVEN; PROVEN) — Sound id indexes the 638-row sdd_dungeon_hunter_2_iphone table. Ordinary rows resolve to the sounds.xml filename; isEvent rows expand member filenames. File existence is checked across the partial Android/recovered-cache and iOS corpora; a file in any included source corpus resolves the row. Evidence: `items-discovery/sdd_dungeon_hunter_2_iphone_pyarray.bin and names; port/engine-audio/reference/source-bindings-v38/ledger.json source_id/event/target; audio-v34/cache/sounds.xml; coordination/v21.8/ATLAS-CODEX-PROMPT.md and user clarification that Android/recovered-cache and iOS are both partial sources.`
- **asset-platform-availability** (PROVEN; PROVEN) — Asset presence is recorded per actual source corpus and resolved paths retain their source labels and content hashes. Platform availability differences are diagnostics, not substitutions or grounds to suppress a match from another included original corpus. Evidence: `coordination/atlas/data/platform-comparison.json; coordination/v21.8/ATLAS-CODEX-PROMPT.md; user clarification 2026-10-13.`
- **path-case-resolution** (PROVEN; PROVEN) — Atlas lookup policy: compare a data URI with actual source file paths using exact case first, then case-insensitive comparison, preserving ambiguous candidates. This policy alone does not prove original native case semantics. Similar basenames remain candidates, never resolved targets. Evidence: `tools/atlas/references.py _resolve_file; actual source path inventory; port/windows-foundation/asset_catalog.cpp:15 and :165 normalize port lookup case.`
- **pydata-literal-oid** (PROVEN; PROVEN) — A literal GetPyOID(tableAlias,rowName) resolves only through a proven PyDataArrays public alias and an exact case-sensitive source names-stream match; GetPyStruct names a struct member and is not treated as a row lookup without a matching native field schema. Evidence: `ida-apk-export-2026-10-07/libraries/classes.dex/pseudocode-all.c PyDataArrays constructor/GetOID/GetPyOID wrappers; port/android-native/app/src/main/cpp/source_process_array_registration_v101.hpp; exact Android names streams.`
- **character-charpropsname** (PROVEN; PROVEN) — An authored charpropsname on a gametype="Character" record conditionally identifies an exact CharacterTable row when char_template does not take precedence. This is a source relationship, not proof that the actor spawned at runtime. Evidence: `native GetCharPropertiesId 0x3b3d38; canonical_property_declarations_v1.inc:68; canonical_character_family_v4.cpp:40-47; port/windows-foundation/actor_population.cpp:144-170.`
- **character-sounds-table-group** (PROVEN; PROVEN) — CharacterTable.Sounds indexes the first registered sounds-array group exposed as CharSoundsTable (sounds#group0). This establishes only the row namespace; sound payload fields and any SDD/audio relationship remain undecoded. Sounds_bak is a separate later registration group. Evidence: `native Character::GetCharSoundsId 0x3a3294 and GetCharSounds 0x3a32d0; source_process_array_registration_v101.hpp:113-114 (CharSoundsTable) and :121-122 (Sounds_bak).`
- **skill-script-uri** (PROVEN; PROVEN) — SkillTable.Script is a stem, not a path. Resolve it only to an exact data/scripts/skills/<stem>.luac logical-path match and retain all source variants for that URI; basename-only matches are not resolutions. Evidence: `port/game-data/skill_tables.cpp SkillTable.Script string field; supplied original data/scripts/skills files and exact logical-path comparison in tools/atlas/references.py.`
- **skill-icon-swf-symbol** (PROVEN; PROVEN) — A nonempty SkillTable.SkillIcon is a SWF symbol label, not a standalone image file. Resolve it to the exact label/frame in sprite 79 of dqcharmenu_droid.swf; retain the SWF asset identity and hash. Missing labels or SWF assets remain unresolved. Evidence: `Original skill presenter mapping in tools/atlas/entity_profiles.py; port/windows-foundation/features/skill_ui/source_skill_art.json label/frame extraction; original SWF asset hash.`
- **itemdrop-visual-token** (PROVEN; PROVEN) — LootAudioVisual.Visual is a scene-node token passed to the fixed itemdrops.bdae template, not a physical file path. Preserve the token and template asset candidates, but leave its node match unresolved unless an independently parsed source scene receipt proves the exact binding. Evidence: `port/game-data/loot_audiovisual_v8.cpp:10; recovered ItemObject::InitOnce 0x3ece80; tools/atlas/entity_profiles.py resolve_item_resources and source-scene receipts.`
- **level-scene-prefix** (INFERENCE; LIKELY) — The decoded Levels.LevelFile is a bare scene filename. The Windows transition consumer prepends data/scene/; the atlas looks up scene/<LevelFile> within each included data root. Original native loader behavior beyond the recovered table schema remains unconfirmed. Evidence: `port/game-data/level_tables.cpp:63; port/windows-foundation/features/transitions/level_transitions_v1.cpp:113.`
- **signed-reference-sentinels** (PROVEN; PROVEN) — Typed signed table-index fields use signed 32-bit values; negative values such as -1 mean no reference and are omitted from reference rows, never reinterpreted as large unsigned IDs. Evidence: `port/game-data/skill_tables.cpp signed_word and Skill Anim field; Projectiles registered source descriptor and signed row fields; exact source pyarray bytes.`
- **bdae-sound-prefix** (PROVEN; PROVEN) — BDAE sound events strip exactly one leading `sfx_` before lookup in sounds.xml; preserve the resulting label verbatim, including malformed or missing names. Evidence: `port/engine-audio/reference/source-bindings-v38/ledger.json; adapter.cpp sound event mapping; BDAE event sites from tools/atlas/sites.py.`
- **unsupported-pyarray** (PROVEN; PROVEN) — An undecoded PyData payload retains its proven table name and local row index with terminal UNRESOLVED/OTHER disposition; its fields remain unknown pending a recovered parser or native schema. No fields are inferred from adjacent bytes. Evidence: `Native count-prefixed names streams plus exact decoded schemas in port/game-data/animation_tables.cpp, effects_tables.cpp, skill_tables.cpp, and data.cpp.`
