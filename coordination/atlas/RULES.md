# Reference resolution rules

- **pydata-name-blocks** — PyData name blocks are count-prefixed lists of length-prefixed UTF-8 strings; row index is zero-based in serialized order. Evidence: `port/game-data/animation_tables.cpp Reader::strings and load_animation_tables; port/game-data/effects_tables.cpp Reader::names.`
- **audio-row-index** — Sound id indexes the 638-row sdd_dungeon_hunter_2_iphone table. Ordinary rows resolve to the sounds.xml filename; isEvent rows expand member filenames. File existence is checked across the partial Android/recovered-cache and iOS corpora; a file in any included source corpus resolves the row. Evidence: `items-discovery/sdd_dungeon_hunter_2_iphone_pyarray.bin and names; port/engine-audio/reference/source-bindings-v38/ledger.json source_id/event/target; audio-v34/cache/sounds.xml; coordination/v21.8/ATLAS-CODEX-PROMPT.md and user clarification that Android/recovered-cache and iOS are both partial sources.`
- **asset-platform-availability** — Asset presence is recorded per actual source corpus and resolved paths retain their source labels and content hashes. Platform availability differences are diagnostics, not substitutions or grounds to suppress a match from another included original corpus. Evidence: `coordination/atlas/data/platform-comparison.json; coordination/v21.8/ATLAS-CODEX-PROMPT.md; user clarification 2026-10-13.`
- **path-case-resolution** — Resolve a data URI against actual source file paths using exact case first, then case-insensitive comparison; preserve ambiguous candidates. Do not infer missing content from a similar basename. Evidence: `atlas path-resolution implementation; source path inventory.`
- **signed-reference-sentinels** — Typed signed table-index fields use signed 32-bit values; negative values such as -1 mean no reference and are omitted from reference rows, never reinterpreted as large unsigned IDs. Evidence: `port/game-data/skill_tables.cpp signed_word and Skill Anim field; Projectiles registered source descriptor and signed row fields; exact source pyarray bytes.`
- **bdae-sound-prefix** — BDAE sound events strip exactly one leading `sfx_` before lookup in sounds.xml; preserve the resulting label verbatim, including malformed or missing names. Evidence: `port/engine-audio/reference/source-bindings-v38/ledger.json; adapter.cpp sound event mapping; BDAE event sites from tools/atlas/sites.py.`
- **unsupported-pyarray** — An undecoded PyData payload retains its proven table name and local row index with terminal UNRESOLVED/OTHER disposition; its fields remain unknown pending a recovered parser or native schema. No fields are inferred from adjacent bytes. Evidence: `Native count-prefixed names streams plus exact decoded schemas in port/game-data/animation_tables.cpp, effects_tables.cpp, skill_tables.cpp, and data.cpp.`
