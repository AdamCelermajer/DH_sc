# Workforce dispatcher

Role: coordinate bounded feature work for `/root`. Root owns priorities, main/CMake/core actor changes, native fixture/build/closure, release, and final verification. The integration lead owns ownership grants and caller integration review. This dispatcher owns the workforce board and feature-task routing; it does not edit gameplay, root build, or release files.

## Dispatch policy

- Maximum 25 live agents; count the three orchestrators and target no more than 22 feature workers.
- Use Luna HIGH for bounded feature work. Sol MEDIUM requires lead-approved architectural complexity.
- A helper or fixture is not live-gameplay acceptance. Keep source gaps and root caller boundaries explicit.
- Prefer concrete source-backed feature implementation over duplicate reports, native graph prerequisites, or speculative providers.
- Ask the lead for a narrow source ownership grant before touching shared files. Root owns main/CMake and shared runtime unless explicitly granted.
