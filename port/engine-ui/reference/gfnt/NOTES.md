## Renderer contract

Load caller-provided bytes with `GfntFont::load`, retain `Borrow`, then call `Borrow::raster(out, codepoint, source_font_height, error)`. A present result1 owns `rgba`, containing consecutive RGBA pixels in the original record's row order. For the actual cache these cells are16×19 with pitch64. Data coordinates are exactly the cell grid `[0,width)×[0,height)`. There is no tint, alpha premultiplication, vertical flip, atlas padding or invented screen placement. Source source-font-height is the signed integer originally supplied to get_char_image, not a newly inferred screen-pixel size.

`source.metrics` exactly preserves original five words: unsigned bearing_x, unsigned baseline, width, height, signed advance. `advance_twips` is the original cached-glyph wrapper's `float(advance)*20.f`. `source_font_scale` is the original constructor output; actual SCT header19 produces51.2. Original record bytes contain bearing_x and a right-edge word; rawAdvance is uint32(header word8+1+right-bearing_x), then reinterpreted signed32. The exact float sequence is `a=float(source_font_height); a=a*20; denominator=1024/a; scaled=float(rawAdvance)*denominator; advance=ARM_f2iz(scaled)`. No reassociation/FMA is allowed. Original imported compiler conversions are explicit IEEE services in the oracle, including defined signed saturation and arithmetic NaN-to-zero conversion.

Missing/empty codepoint result0 preserves caller output and does not manufacture a fallback glyph. Malformed result-1 also preserves output. `error` describes malformed ownership/input, while source miss is an empty error. Borrow prevents reloading the active facade and survives destruction of its facade/input byte vectors. Borrowed backing is immutable; no caller pointer into input bytes survives load.

Atlas location, cache size requirements, normalized glyph rectangle transformation, text pen/matrix, style/filter and texture upload must use original cache/layout services. The captured cached wrapper at `0x7c59dc` first asks original texture-cache size requirements with width+1/height+1, then computes its four rectangle words and cached advance before returning the cache texture. This module exposes the required raw metrics but does not assume those rectangle words are final screen coordinates or invent an atlas. Actual source shader primitive has separately been recovered by the effects worker; GPU/bitmap provider connection is parent-owned.
