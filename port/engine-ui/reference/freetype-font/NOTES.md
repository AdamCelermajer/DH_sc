# Source font connection

The original ELF `36498eb8180ffb74759e6305e9596db999f18583d460f3b8534abcb6022f5e80` writes FreeType version **2.3.7**. The official source archive and original/native file inventories are bound here. Portability corrections in three files avoid an unused pointer before a null edge array, zero-byte copies/moves of null outline arrays, and negative signed byte shifts in field extraction. Archive bytes remain untouched. FreeType license/notices are retained in the vendor directory.

The native backend owns exact caller font bytes, the FT library and the face. It has no filesystem resolver or substitute font. It implements the original `glyph_provider::get_char_image` (`0x7d1614`) **no texture-atlas branch**: requested font size is converted to float32, multiplied by the context scale, truncated to a pixel height, then passed to `FT_Set_Pixel_Sizes(face,0,height)` and `FT_Load_Char(face,code,4)`. The source `draw_bitmap` (`0x7d06c4`) chooses power-of-two alpha image width at least the FT pitch and at least four, and height at least rows and at least one; it copies exactly bitmap.width bytes per row into zero padding. Positive grayscale pitches are supported; other bitmap formats fail explicitly.

Source normalized bounds are `bitmap.width/image.width` and `bitmap.rows/image.height`, with x origin `-(horiBearingX/metric.width)*xExtent` and y origin `(horiBearingY/metric.height)*yExtent`; nonpositive metric extents produce zero origins. Advance is float32 `horiAdvance*(16/requestedFontSize)`. Font3's caller multiplication remains in the core. The original-versus-O2 ARM64 proof executes the original no-cache provider and alpha-copy instructions for **570 real Fontin metric/image inputs**, comparing all layout words and padding, with **5,700 explicit service deliveries**. Face lookup, cache/allocation, FreeType glyph production and bitmap upload are controlled boundaries. Matching version is not a claim that the original complete FreeType options/raster leaves were instruction-compared.

`SwfFreetypeProvider` supplies the real core's `glyph_provider` interface. It resolves exact caller-supplied font-name/style bytes, retains faces and actual bitmap objects, and caches source `(code | fontSize<<16)` entries. Source resolver misses are cached. No global provider is changed by this module. Give `borrowed_provider()` to `SwfServices.glyphs`; the facade scopes provider installation. `SwfServices.image` receives the source padded alpha synchronously. Its returned texture identity, the resolver context and texture owner must outlive every dependent movie. Recreate GPU textures from retained CPU bytes as the renderer requires.

The actual shared+Android HUD emits genuine Fontin glyph uploads and bitmap quads. The diagnostic baseline observed **238 alpha uploads, 232 nonempty images and 1,032 bitmap quads**. It also requested **Arial**, which remains unresolved in this bounded exact-Fontin provider. That request is recorded, never substituted with SCT or another font. The small embedded glyph is `.` (code 46). General menu/font resolution and localization/game globals remain separate services.

Upstream GameSWF1714 overwrites a successful provider's advance with its embedded advance table; original DH2 returns provider advance first. This fork difference remains explicit for the embedded dot and other mixed-provider fonts. Geometry access copies actual public glyph paths/edges into owned data without rasterizing, rescaling or replacing the core provider.

Add `freetype_font.cpp`, `freetype_glyph_kernel.cpp`, `swf_freetype_provider.cpp`, and `swf_font_geometry.cpp` to the UI library. Link matching FreeType and the native GameSWF core; their include directories must propagate. The core's configuration definitions must match its build. Android O2 syntax checks cover all 34 backend/wrapper source units for both ARM64 and x86_64 (68 checks), independently of APK/device proof.

Host audit source is `tests/freetype_font.cpp`; arguments are `<actual extracted SWF directory> <exact Fontin SmallCaps.ttf> <output PGM path>`. `DH2_FONT_RASTER_ONLY` runs the standalone backend (570 rasters, 2,284 checks, five atomic guards, ASan/UBSan/LSan zero). Full mode links the movie facade/core and verifies real HUD uploads, owned outlines and draw requests with explicit borrowed host texture/localization/native-function fixtures. Historical baseline core leaks are preserved in the diagnostic report; the final full-core report is separate. No GPU, packaged or live-device parity is claimed here.
