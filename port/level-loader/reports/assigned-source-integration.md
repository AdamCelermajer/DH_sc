The reviewed nine-file stream seam is installed in the active private loader.
Fixed files and assigned generated documents feed the same canonical file walk,
factory attempt journal and module collection. Root mode is selected from actual
Level140 and remains stable for that occurrence. Native receiver liveness is
checked around callbacks, and failed release retains ownership for retry.

after successful teardown without replaying completed unload.

The existing meaningful source cases are retained under
tests/assigned-source-milestone for the next integrated validation suite.
No compiler or runtime test was run during this integration.

The actual LoadFileData assignment/copy, retained native TiXML parser, cursor and
release kernel is still being implemented in the separate working v65 tree.
Those loader algorithms are not delegated to Main as whole-body callbacks.

Complete SWAMP rendering, interactions and all-level runtime acceptance remain
open. Validation is scheduled only at the agreed major milestones.
