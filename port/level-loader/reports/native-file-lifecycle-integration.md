# Native file and lifecycle integration

The coherent working kernel is installed in the isolated loader. Fixed-file
open/copy/publish140/close and generated-stream copy both reach the same retained
native TiXML parser, immutable source projection and canonical factory journal.
The actual Level owns its assigned resource independently of driver wrappers.
Cleanup composes generator quiescence, temporary stream destruction, source-handle
close, genuine world unload and native document/assigned-state release. Completed
steps remain cached across explicit failed-release retries.

Native engine filesystem/stream/debug leaves and allocator integration remain
explicit production dependencies. This change implements loader algorithms; it
does not substitute authored content, grant readiness or invent game state.

The existing coherent context and source-stream headers changed. All dependent
objects must be rebuilt together at the integrated milestone. Historical context
archives and syntax results do not validate this current graph. One new source
target is wired into the private loading dependency closure. No native job,
build, test, emulator, WSL or shared-checkout mutation ran in this integration.
Complete SWAMP rendering and all-level runtime acceptance remain open.
