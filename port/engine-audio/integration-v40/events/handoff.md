This packet is concrete prospective source work for ONE shared `AudioGameplayRuntimeV40`. Shared renderer/native_app/CMake, V34, V38 and frozen artifacts were not edited. There is no root build, link, APK, emulator, ADB, audio-driver launch or audible acceptance claim. All changes are new helpers, diffs and private captured/prospective trees under this directory.

## Runtime transport contract

`audio_session_transport_v40.hpp` is the PRODUCTION binding: it routes the typed `AudioProducerTransportV40` through the ONE owning AudioNativeSessionV40.submit_actual_play, preserving producer-thread/accepting-state and independent UI close exclusion before its actual runtime method: `submit_actual_play(const CombatSoundPlayV1&, int64 source_event_monotonic_ns, string& error)->bool`. True includes original early returns; false is explicit required/malformed/provider failure. Root retains actual contexts/lifetimes and can read runtime `last_source_status()`/`last_source_phase()` diagnostics. This packet does not infer an audible result from true.

The event-clock callback must provide the actual **positive source-event monotonic timestamp**. Root resolves authored lag from its actual scheduler/producer scope; this packet never calls now(), derives wall time from dt, creates a private epoch or fabricates phase38. The helper queries source time at the reached delivery before synchronous submit. Actual source-event scope must be established/restored around sequence selection, player/NPC authored events, common result/target events, and real container/item lifecycle events, including nested callbacks. Parent runtime snapshots time per submit and rejects runtime reentry rather than corrupting an outer request clock.

Root binds `PlayerSkillsRuntime.audio_producers_v40` to `audio_session_transport_v40(actual_owning_session, actual_event_scope, actual_event_time_callback)` before reached deliveries. It must borrow the SAME actual manager, current GS/Level gates, selected XML, source bindings, listener/source command authority, RNG, bank/mixer and output owner. Those are parent construction duties; this packet creates none. There is no duplicate Vox-prefix check in the staged emitters: the shared runtime alone executes source gates once.

The separate `audio_runtime_transport_v40.hpp` direct bridge is for controlled independent fixtures only; it bypasses session close exclusion and MUST NOT be used by production renderer services.

Every request field, manager snapshot, subject annotation, signed source ID and copied position is forwarded. Ordinary animation and generic target requests retain their existing target0 annotation; named sound carries actual actor; combat carries actual target; item carries actual Item. Parent `source_command` must interpret those actual contracts rather than invent an actor for target0. Negative IDs still execute their source producer prefix and reach the runtime's negative-ID gate. Unknown names remain source no-op; missing exact clips are runtime errors, never substitutions.
