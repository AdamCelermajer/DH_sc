# Original structured field IDs and shared script execution

The source runtime now installs `GetPyStruct`. It shares the class map and lookup
callback with `GetPyOID`, matching the original callbacks' calls to
`PyDataArrays::GetOID` (ELF `0x004bd640`). Original callback addresses are
`0x0037f4a8` and `0x0037f5fc`; this call-chain observation comes from the preserved
assembly. Full original C++ `Value` conversion and manager map lookup are not
executed by these tests.

## Field name evidence

[The original trace](../../reports/pydata-struct-name-trace.json) executes the
51,576-byte initializer at ELF `0x004ddeb8`, plus the actual string constructors,
range initialization and allocation-block selection. Pool allocation, libc
`strlen`/`memcpy`/`strcmp`, and exit-handler registration are explicit bounded
models. Destructors and historical allocator behavior are outside scope.

The trace reads **636 entries from 71 registered Structs tables**, including
224 `CharacterProperties` names. It executes all registered original lookup
bodies against every distinct name and one missing name per table: **693 checks**.
Each 24-byte original string's start/end pointers agree with the captured text.
Ghidra addresses have a separate 0x10000 offset; the trace uses ELF addresses.

Five registrations share `ColladaFile`, each with the same `Name` field, giving
67 unique registered class names. `Item` includes 15 empty field names at indices
23–37; the original lookup returns the first, 23. These entries are preserved.
The old commented test's `CharAnim/Attack2H` is absent from this original table
and returns -1; it is not invented as an alias.

[The generator](../../tools/generate_pydata_struct_names.py) pins the trace hash
and writes [immutable source tables](struct-names.h). Every runtime build checks
the generated bytes. Runtime creation imports them into owned Lua class maps
under protected initialization. Subsequent imports atomically replace one class;
both lookup functions observe the replacement. Existing malformed/OOM rollback,
caller-buffer release, duplicate and type/count behavior remain checked.

This recovers static field IDs. It does not establish record offsets, typed field
access, cache struct-name overrides, live entity properties or object lifetimes.

## Three exact recovered scripts now execute

The source runtime executes unchanged manifest/hash-checked sources:

- `ai/_commons.luac`
- `skills/_commons.luac`
- `level/combat_formulas.luac`

[The harness](../lua-runtime/tests/structs_corpus.py) then checks 1,272 authored
`GetPyStruct`/`GetPyOID` alias queries against all 636 field entries. Additional
authored calls exercise the original shared animation-event dispatch/detach and
skill registration/defaults/select/unselect. Combat definitions load and their
no-combatant paths run. No entity callback, real combat calculation, timer, AI
behavior or game loop runs. Original interpreter/gameplay equivalence is unproved.

These tests pass on [host](../lua-runtime/structs-host-execution-validation.json),
[strict host sanitizers](../lua-runtime/structs-host-sanitizer-execution-validation.json),
[Android 17 / 4 KiB](../lua-runtime/structs-android-4k-execution-validation.json) and
[Android 17 / 16 KiB](../lua-runtime/structs-android-16k-execution-validation.json).
Each emulator verifies all six staged script/list/assertion/runner hashes before
execution. Both use the same source-built x86_64 runner. ARM64 is cross-built with
16 KiB load alignment, without hardware execution. No Fold7 is tested.

Updated regressions pass for all 8,863 array-name queries, 5,608 constants, 504
arithmetic vectors and 220 compilation inputs on host and both Android page
sizes. The original malformed sandworm remains unchanged and fails parsing;
its separate repaired override passes. Current build reports:
[host/sanitizers](../lua-runtime/structs-host-build-validation.json),
[Android NDK](../lua-runtime/structs-android-build-validation.json).

This checkpoint is a standalone source runtime component. Source APK integration
and full source-built gameplay remain unfinished. The [rights statement](../../RIGHTS.md)
applies to recovered game metadata and scripts.

## Reproduce

```sh
python3 tools/trace_pydata_structs.py --help
python3 tools/generate_pydata_struct_names.py --check
python3 port/lua-runtime/build.py --host --sanitize --report /path/to/build.json
python3 port/lua-runtime/tests/structs_corpus.py --runner /path/to/runner --report /path/to/run.json
```

Tracing uses the owner's exact original library and Unicorn/pyelftools. Source
builds and the three-script execution test use only checked repository sources.
