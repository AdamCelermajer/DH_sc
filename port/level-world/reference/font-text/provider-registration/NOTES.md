# Original menu font providers

The captured original ELF is SHA256 `36498eb8180ffb74759e6305e9596db999f18583d460f3b8534abcb6022f5e80`. Function bytes and addresses are bound by the adjacent capture manifests.

`RenderFX::CreateContext` (`0x7a9708`) always constructs the FreeType glyph provider (`0x7d0dfc`, context offset `0x0c`) and the bitmap provider (`0x7a9698`, context offset `0x10`). Zero texture-cache dimensions do not omit either provider. The default initialization overload supplies zero cache dimensions, enabled byte 1 and scale 1. `InitializeGlyphTextureCache` (`0x7a8d74`) is a trace-only body.

The bitmap entity lookup (`0x7c6048`) compares extensions `.fnt` and `.FNT`: the second literal is at `0x90b110`, referenced by `0x7c62c0`. Earlier `font-text/NOTES.md` inferred `.ttf` for this branch; that inference is superseded by the actual literal extraction in this directory. True TTF paths therefore miss the bitmap provider and reach the FreeType provider. This correction does not change the frozen GFNT raster implementation or its corpus.

Original `font::get_glyph` (`0x7d01bc`) initializes advance to 512 and index to -1, tries bitmap first, then FreeType, and finally tries the embedded code/advance tables. A successful bitmap result returns its provider advance, multiplied by 20 when the font alignment-zone table is nonempty. The FreeType success path joins that same multiplication/return branch. Upstream GameSWF1714 instead loads the embedded glyph index first and overwrites successful-provider advance with its embedded advance table. Provider-aware upstream metrics therefore require this fork distinction to remain explicit.

`FT_Init_FreeType` (`0x70d708`) writes library version fields at offsets `0x0c/0x10/0x14` to **2/3/7**, identifying FreeType 2.3.7. The 18 executed initialization/version cases in `../freetype-version/original-probe.json` execute original `FT_Init_FreeType`, `FT_New_Library` and `FT_Library_Version`. Memory allocation and default-module registration are controlled services; this proves the version and observed ordering, not full rasterizer parity. FreeType's [official downloads page](https://freetype.org/download) identifies official source distribution channels; no modern replacement library has been substituted.

For the first native HUD connection, an embedded-font outline wrapper may read the real core's public glyph/code/path APIs without changing its global provider. Such owned quadratic paths describe actual authored geometry, not a FreeType or original final-screen layout proof. A provider-null core is an explicit bounded configuration, not the original default. Original language, file-manager rewriting, external font resolution, cache upload and glyph draw transforms remain separate services.
