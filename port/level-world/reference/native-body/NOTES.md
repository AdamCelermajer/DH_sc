# Genuine native physical-body adapter

`native_body.hpp/.cpp` binds the recovered PhysicalObject controls and pin/unpin lifecycle to public Box2D 2.0.1 methods and the actual world, shapes, mass, proxies and broadphase. Parent `NativeWorld` owns the body/world. `NativeBody` carries the real body pointer, original physics-unit radius and original pinned boolean.

Linear requests/increments wake only when either supplied component compares unequal to zero. AddLinearVelocity clamps only above each supplied upper bound. Angular velocity always wakes, including both signed zeros. These explicit wakes matter because this release's public velocity setters do not wake. Queries scale XY/radius by 100; position writes scale game XY by .01 and retain current angle.

Stop sets zero velocities, wakes through the angular setter, invokes genuine SetXForm ignoring its return value, then genuine PutToSleep. This clears genuine internal force/torque through the release API. Pin sets its boolean before genuine SetMass(0, current local center, 0); unpin clears its boolean before genuine SetMassFromShapes and then wakes. Both are idempotent.

The subobjects service bridge performs genuine transforms/velocity/wake and refreshes the public part of its logical view. The `physical_update` event refreshes only; the caller owns world-Step timing. Other events forward to the caller. No private-access macros are used. Observation includes only public position, angle, velocities, mass/inertia, local/world center and observable booleans. Refresh preserves logical force/torque/sleep-time and other flag bits because Box2D does not expose these publicly; those retained fields are not claimed as native-body observations.

The ARM64 original-instruction differential runs 48 worlds and 1,776 public-state/game-query comparisons, including 576 actual original/native Steps. Original full Stop runs its actual empty DropPath, actual Character policy getter, actual physical setters and actual complete Box2D transform. Shape/mass/proxy/broadphase/Step services are never intercepted. Allocation, libc and imported arithmetic/trig are desktop CPU fixtures. Finite compared words match exactly. The 144-byte record corpus hash is `d2c353252f7a2db97b7c5d85b9cdd1959afee45e0f9e46a4c641f41cae7978ee`.

ASan/UBSan host replay matches all 1,776 records exactly with test-only modeled trig imports. An independent host test adds 163 real world Steps and collision contacts, verifies pinned bodies remain stationary and unpinned bodies move, verifies Stop clears applied force through a subsequent step, and checks native subobjects services and five atomic malformed-input rejections. Position/transform inputs require finite values at the native binding. Corpus worlds use valid finite producer state; exhaustive IEEE velocity edge behavior remains separately covered by the physical-controls instruction corpus. The host fixture uses actual native contact resolution, while this adapter differential deliberately has one authored circle per world; full multi-shape/contact/TOI source verification is in the physics-backend reports.
