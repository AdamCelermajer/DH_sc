# Native Character Stop adapter

Composes the verified GameObject::Stop kernel with live Coordinator flags, owned navigation storage and pinned Box2D 2.0.1. Coordinates convert centimeters to meters. False SetXForm is an ordinary ignored source return; malformed providers preserve completed effects.

Logical destination/heading/movement writes publish before observing services. Live fields and body identity reload after callbacks, including failure/exception paths. Known owner ranges reject aliases before mutation. Borrowed actors, route, wrappers, bodies, world and contact owners must survive the synchronous call.

Host gate passes 14 scenarios across 31 Box2D source units, including real contact-callback reentry, callback edits, replacement-body final sleep, partial failures, aliases and the subsequent cleared-route frame.

Run: `python port/level-world/tests/run_native_character_stop_host.py`.
Evidence: `build/native-character-stop-host/validation.json`.

No Android renderer activation or autonomous AI is claimed.
