## Native diagnostic

Configure this directory with Windows llvm-mingw and Ninja. `FOUNDATION_BUILD` selects existing foundation static libraries; the diagnostic neither changes nor rebuilds the gameplay executable. Run CTest in the resulting directory.

```
dh-frontend-diagnostic.exe --assets <original Android assets directory> --screen main --frames 2 --capture main.ppm
dh-frontend-diagnostic.exe --assets <original Android assets directory> --screen class --preview --class 0 --frames 3 --capture class.ppm
```
