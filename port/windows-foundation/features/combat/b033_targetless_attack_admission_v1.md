# B033: targetless ordinary Attack admission

## Result and scope

This focused regression confirms a source-vs-Session admission gap. The recovered `CharAI::AI_DoMeleeAttack` empty-search branch requests the ordinary Attack state with a null target after its source gates; the current diagnostic `CombatSession` path remains Idle when Space has no current or eligible candidate. The same-session live-target control passes. No behavior patch was made because root owns `combat_session.*`.

This is state admission only. It does not claim a hit, damage, animation event, or successful normal executable input path. It is separate from B003's living-target Skill Post→Space reacquisition regression.

## Original behavior evidence

**Visual.** Inspected the supplied *Dungeon Hunter 2 (v1.0.3) Part 1* sequence at 281.995, 283.278, 284.995, 286.328, and 287.995 seconds in `.local-inputs/referenceframes/dh2-act1/target-combo-v1/`. The Warrior and Bogwomps remain in view; frames show a target ring/name/health bar, changed melee poses, a “Miss,” damage numbers, an enemy body on the floor, and later “8 XP” while another combatant is present. This demonstrates ordinary melee/target continuity in that clip. It does **not** reveal the Space key, target state at command admission, or an attack entered with no target. Thus it cannot visually settle targetless admission. The clip is v1.0.3 while the recovered source cache is v1.0.2; a version difference remains possible.

**Logic.** The recovered executable corpus is `port/level-world/reference/prince-live-attack/melee-probes.json` (SHA256 `CC2C080D82BE85BC6D56A19A1BCE499D1978A1C93296BC946261A55715380289`), bound to the original ELF SHA in its manifest. Its empty-search case has `dead=0`, `blocked=0`, `range=0`, `attacking=0`, `last=0`, `heading=0`, `found=0`, `mode=0`, `explicit=0`, `current=0`, and `ooi=0`. The original trace is `IsDead` → owner `+0x528` bit0 check → `CanRangeAttack` → target list create/search → empty result/list destroy → `state_event(0xc354, payload=0)`. This is the precise source case: with no candidate and no OOI fallback, a new ordinary melee command still requests C354 with a null target.

The outer route still has gates: `v2Controller::Cmd_Attack` (`0x405b04`) rejects global blocked or local locked input unless forced; `Character::Ctrl_Attack` (`0x3ad87c`) delegates to `AI_DoMeleeAttack` (`0x3d01ac`); dead owner returns, owner `+0x528` bit0 blocks, and ranged capability redirects to `AI_DoRangeAttack` (`0x3d076c`). An already attacking actor with last flag `+0x79` set returns; the continuing-attack branch does not raise a new C354. Search/target selection still runs for the new melee path. If OOI is type 8 and heading is inactive, source assigns the OOI and synchronizes last-target before deciding whether the target remains null. For ordinary mode=false, a nonnull current target must pass `AI_IsInMeleeRange` (`0x3d6188`); a null target skips that target-specific range test and reaches `SM_SetAttackState` (`0x3c6488`). Its false branch raises C354 (`0x3c5684`). The source state machine admits C354 from Idle3/Move4 only when owner `+0x528` bit1 is clear (`CSM_Attack`, `0x3ad22c`; see `port/level-world/reference/character-state/NOTES.md`). Therefore targetless eligibility does not bypass owner, controller, ranged, continuation, OOI, or state-machine gates.

**Session contract.** In `combat_session.cpp`, `command_request` (`:842-859`) uses `diagnostic_attack_body` when no controller-admission provider is configured. `diagnostic_attack_body` resolves the requested target or `nearest(source)`, turns, then calls `request`. `request` (`:832-840`) returns without starting the attack if the target is null/missing, permission is absent, animation owns pose, cooldown remains, the action is ineligible, the candidate is ineligible, or melee range fails. The B033 fixture's cleared actors produce no eligible nearest target, so Session never begins `Attack`. This diagnostic route is narrower than the original controller path; production provider configuration and real input admission are outside this focused test.
