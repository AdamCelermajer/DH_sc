# Hex-Rays export: libDungeonHunter2.so (ARM)

Full IDA 9.4 Hex-Rays pseudocode export of the game binary, produced on the
Windows PC from the user's IDB.

- 31,724 functions in 64 chunk files, `chunk_000.c` to `chunk_063.c`.
- Each function starts with a header line: `// ===== <address> <name> =====`.
- Files keep the CRLF line endings they were exported with.
- Pseudocode only. These files are for reference and are not compiled.
- Other export files from the same run (names, strings, xrefs, structs) are
  not in this folder.
